# 📜 Cordel Moderno

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Google Fonts](https://img.shields.io/badge/Google%20Fonts-4285F4?style=for-the-badge&logo=googlefonts&logoColor=white)

Esse é um projeto de front-end feito para transformar o **Cordel Moderno**, de Milton Duarte, em uma página web com visual mais elaborado, misturando poesia, imagens e efeitos de rolagem.

## ✨ Sobre o projeto

A página apresenta o texto do cordel dividido em seções, alternando partes com fundo simples e partes com imagens de fundo. A ideia foi criar uma leitura mais visual, usando o efeito parallax para dar profundidade enquanto o usuário rola a página.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Imagens de fundo
- Efeito parallax com `background-attachment: fixed`
- Variáveis CSS com `:root`

## 📚 O que eu pratiquei

- Estruturação semântica com `header`, `main`, `section` e `footer`
- Organização do conteúdo em blocos de leitura
- Uso de fontes externas para personalizar o visual
- Aplicação de imagens como plano de fundo
- Criação de efeito parallax
- Uso de sombras, contraste e sobreposição de texto
- Responsividade com unidades como `vw` e `vh`

## 💡 Tipo de projeto

Esse é um projeto de estudo focado em HTML e CSS. Ele ajudou a praticar não só a estrutura da página, mas também a parte visual, mostrando como pequenas escolhas de fonte, imagem e espaçamento mudam bastante a experiência de leitura.
